# Entrega de maquetado HTML

> Documento de la primera actividad de HTML. La nueva actividad añade CSS externo; consultar `docs/estilos-css.md`.
## Abrir las páginas

Abra `frontend/index.html` en un navegante. No se requieren dependencias de NetBeans, Java, MySQL ni instalaciones. Todos los enlaces internos utilizan rutas relativas.

También puede usar un servidor estático desde la razón del repositorio:

```bash
python3 -m http.server 8000 - interfaz de dirección
```

La entrega contiene exclusivamente HTML e imágenes, sin CSS ni JavaScript. La apariencia predeterminada del navegador es internacional: la guía deja los estilos para la orientación actividad.

## Actividades realizadas

| Clase | Evidencia |
|---|---|

| 4 | Menús con `nav`, `ul`, `li` y `a`; pasos de uso con `ol`. |

| 6 | `encabezado`, `principal`, `sección`, `pie` y tres `articulo` estructura común en inicio; `aparte` en el panel. |

| 8 | `multimedia.html` con video y mapa incrustados; comentarios que explican tres clases y un identificador. El mapa muerte la Universidad de Pamplona, sede principal. |

## Alcance y pendientes

Los formularios son maquetas: no hay backend web, persistencia ni inicio de sesión real en HTML. El proyecto Java adjunto no fue modificado. Las ocho capturas suministradas están mapeadas en docs/pantallas.md y preservadas en docs/prototipo/.

Se compara las ocho capturas del prototipo y se utiliza el logo original del proyecto Java. El reparto de integrantes es propuesto; no se atribuyen deportes ni revisiones que no han ocurrido.
