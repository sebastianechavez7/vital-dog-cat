# Vital Dog Cat

Aplicación de escritorio para la gestión de inventario y ventas de la veterinaria Vital Dog Cat.

## Integrantes
- Luis Sebastian Echavez Carreño

## Descripción
Sistema desarrollado para apoyar la gestión de la veterinaria Vital Dog Cat, permitiendo administrar productos, inventario, ventas, usuarios y reportes.
