Cómo utilizar la aplicación

  1. Iniciar sesión con el usuario asignado.
  2. Elegir un módulo desde el panel principal.
  3. Consultar el inventario y los registros disponibles.
  4. Registrar los datos autorizados según el rol del usuario.
  5. Cerrar la sesión al terminar.
